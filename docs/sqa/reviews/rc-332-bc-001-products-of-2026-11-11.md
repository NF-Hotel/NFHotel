- **Targets that are not met on 2026-11-12, stated as targets.** Success criterion 21: the web container gets the passport key as a secret file (`ops/deploy/nfhotel-web/docker-compose.yml`, since 9090645), though objective 18 says it holds none and no code of the web application reads it; MIL-075 plans the fix. Success criterion 27: `postgres:16-alpine` (MIL-073), and nginx and the .NET runtime until the release of pull requests #650 and #649. Success criterion 40: two-factor authentication is not required in the organisation (SEC-01), and the ruleset requires no approval, as ADR-0019 decided; S01 allowed the review to be turned on again on 2026-11-11.

- **The Version History follows the rule.** It had 16 rows with four of them Accepted; it keeps the latest Accepted row and the new Proposed row, and the link definitions that no row uses any more are removed.
- **Not independent.** The AI that walked the checklists wrote the revision; the acceptance is S01's decision.
