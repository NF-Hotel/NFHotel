## Findings

- **Coverage is not the gap.** The validation code and the request objects are fully covered by lines; the gap is that no test sends every endpoint every kind of hostile input, and that the scans do not reach the API. The test takes the endpoints from the API, so a new endpoint is covered without a change of the test.
- **The document is made, not served.** An OpenAPI document served in Production would describe the API to anyone who reaches it; the plan makes it at build time for the scan, and criterion 3 proves that Production answers 404.
- **The fixes are not known yet.** How many defects the test finds is known only when it runs; each becomes a regression test (criterion 2). A fix that would change a rule of the domain is a change of scope, for S01 to decide.
- **New packages.** The document at build time needs packages; they are pinned in the lock files and pass the scans of the pull request like any other.
- **Not independent.** The AI that walked the checklists wrote the plan; the acceptance is S01's decision.
