## Findings

- **Why only the edge.** ADR-0027 deferred the tailnet policy and the Proxmox definitions until a trigger, one of which is a change that causes an incident. The edge is the part that drifted, and the drift that MIL-072 found was a security finding; so this milestone does the edge, and the two deferred parts stay as S01 decided.
- **Nothing applies by itself.** The workflow only reads and compares; a change is applied by S01 or S03 from their own machine. A token that can write Access can open the back office, so it never reaches CI, and the AI never sees either token.
- **The public log.** The repository is public, so the workflow prints only the counts and the names of the objects that differ, never the plan, an identifier or an address (criterion 3).
- **No checklist for OpenTofu.** The framework has no QC checklist for that code; the code review checks it against the ADR and says so (criterion 6). A checklist would be a proposal to the framework upstream, not a change in this project.
- **The first plan decides.** If the first plan shows a difference between the dashboard and the code, the code is corrected until the plan shows 0 changes; nothing is applied to make the plan clean.
- **Not independent.** The AI that walked the checklists wrote the plan; the acceptance is S01's decision.
