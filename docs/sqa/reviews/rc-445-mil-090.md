## Findings

- **The date is the risk.** The exceptions lapse on 2026-12-08. The pull request of tasks 1 to 3 asks S01 to review about 50 lines: the 41 entries of the image scan, the entries that #840 may need, and perhaps the nine lines of ZAP. If that review is not done by 2026-12-07, merges and releases stop on 2026-12-09 until it is. The plan opens the pull request by 2026-12-01 and sets the fallback for #829 on the same day.
- **The verdicts on the alerts rest on reading.** The analysis read the code and the reports of ZAP; it did not run the stack. Tasks 4 to 6 turn the verdicts into tests that fail without their control. Until then, "false" is a reading, not a proof.
- **WARN keeps 11 alerts open.** Decision 7 keeps the three active rules running, so their known alerts stay in code scanning until S01 dismisses them. The other way, IGNORE lines for 10058, 90027 and 40025, would close the alerts and stop the three rules in the full scan. The plan chooses detection over a clean list, and S01 accepted it so.
- **#840 may end in an accepted risk.** If no image built with Go 1.26.11 or later exists by 2026-12-19, and the check finds the affected code reachable, the entry has to say "Accepted" and why. That is S01's decision in the review, and task 1 gives S01 the facts for it.
- **One task goes beyond the action list of the analysis.** Task 3, the warning seven days ahead, answers S01's request to protect against a repeat ("beskytte så de ikke sker igen fremover"): without it, every renewal sets the next stop at most 30 days ahead. S01 kept it when accepting the plan.
- **One number of the analysis was wrong.** The analysis of 2026-11-19 said that 16 of the 18 alerts had no line in the rules file. The count is 13 (1, 1, 1, 5 and 5 alerts of the five rules); the plan uses 13, and the analysis was corrected the same day.
- **The overlap with MIL-089 is kept small.** Task 3 of MIL-089 keeps the nine lines; decision 4 adds only a fallback date. The session that builds MIL-089 was sent decision 4 on 2026-11-19, after S01's acceptance.
- **Nothing in the issues is new to the public.** The tasks name CVE-2026-97054 and the nine images, which issue #840 already shows, and rules of ZAP on the throwaway stack.
- **Mode.** Supervised: S01 accepted the plan on 2026-11-19, and nothing is committed, published or built before S01 asks for it.
