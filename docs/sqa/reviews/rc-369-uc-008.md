## Findings

- **F1, fixed: the postcondition.** "Reading changes no run" did not hold. When the list opens, `BenchmarkRunListViewModel` calls `BenchmarkRunTracker.LoadRecentAsync`, which asks the benchmark service about every queued, running or interrupted record of the last seven days and writes a changed state to the hotel system. Fixed: "Reading changes no stored run; only the records of the started runs listed apart are brought up to date with the benchmark service (UC-009, step 6)."
- **F2, fixed: step 5.** "how many graded tasks each model passed" counted tasks per model. The table counts, per model and task, the passed requests out of the graded ones ("Passed runs out of graded runs, per model and task"). Fixed: "for each model and task, how many of the graded requests passed".
- **F3, fixed: rule 5, the cold request.** "the first to a model in a session, before the model was loaded" put the cold request before the load. The page says that cold is "the first request of a model in its run (it may include loading the model)". Fixed to that. The flag itself comes from the benchmark service; the comment of its DTO in the API says "of a session", and the service was not read.
- **F4, fixed: HTTP status codes.** "(403)" in 1a and "(404)" in 3a are implementation detail (criterion 12). Removed; the refusal and the text stay.
- **F5, fixed: open issue 1.** It said that UCD-001 names the Owner as the actor; since the amendment reviewed in [RC-368], UCD-001 names Hotel staff (Manager). Reworded: US-001.02 names the Owner, who works through the role Manager; whether the story changes is S01's decision (action item).
- **F6, note: no memory measured at all.** When neither the memory of the machine nor that of the GPU was measured, the page shows no memory section; 6a covers the GPU only. Not added; noted for the next revision of the use case.
- **F7, note: the open issues keep their owners.** UC-008 is the use case that the first action item of [RC-105] asks for; the terms of the dictionary and the domain model in that item stay open (open issue 4). The rates that the benchmark service calculates from the dataset stay with the action item of [RC-111] (open issue 3). The threshold and the time limit of US-001.02 get an action item for S04 here (open issue 2).
