## Findings

- **The setting was live before the merge.** The required reviewer was set at 13:34 UTC while the documents were still on a branch, so a release of `main` made before this merge would already wait for S01. That is the order S01 asked for ("gør det"), and the opposite of RC-170, which set the environment after its merge. No deploy was pending at the time.
- **Two pages still say 19 required checks** (Security-Controls, the row "Review and the ruleset"; Workflows, the introduction and the table of the host settings), while the ruleset has required 41 since MIL-059 (SAR-001, SEC-03). Not part of this change; an action item below.
