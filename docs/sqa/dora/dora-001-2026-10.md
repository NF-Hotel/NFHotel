## 3. Reading

This is the month the pipeline came up, so the numbers describe its start, not a steady state:

- **The first CD run was on 2026-10-19.** Before it, nothing reached production through CD, so every pull request merged earlier in October waited for the pipeline itself. That is most of the lead time of 93 hours.
- **All six failures were set-up failures of CD, not bad changes.** The four on 2026-10-19 stopped at the Tailscale step, before the tailnet was joined, because the action got no OIDC client ID and audience; the two on 2026-10-20 failed on the VM (`sudo failed with exit code 1`, then "the deploy on nf-hotel failed"). No failed run changed a service that stayed broken; the incident from the first failure to the first success lasted 31 hours.
- **Releases on 2026-10-20 started no CD run.** The releases of `65d89b8`, `eff2252`, `305e82f` and `7c6f348` succeeded, but no `workflow_run` run of CD exists for them; `305e82f` was deployed by hand. Find out why the trigger did not fire (action 1).
- **The deployed release is not the newest.** The manual deploy chose the release of `305e82f`, while the release of `7c6f348` was already available; the gap is #191 and #192, both documentation.
