Five tests of the abuse cases of SAR-002, each run with its control taken out and then with it in place (MIL-089
task 2, criterion 2). The first four on main at 3cfe3ab (MIL-085 to MIL-088), 2026-11-20, in a worktree of its own;
the test of case 6 is new in MIL-089 and was copied into that worktree before its runs. The fifth, case 11, on
2026-11-21 in the worktree of the branch mil-089-booking-flow-attacked, because its control is new in MIL-089. Each run: the
control taken out in the source, dotnet build of the test project -c Release -warnaserror, the one test with
dotnet test --project <project> -c Release --no-build --filter-method <test>; then the source put back, built again
and the same test run. The addresses are of the documentation ranges or just outside the private ranges of the
stack, the emails of example.com.
