# Wireframes of UC-005

Kept with the use case. They show the screen of [UC-005]; the use case itself names none.

The change-password page, one column, inside the back office layout:

```text
+--------------------------------------------------+
| Change password                                  |
| (notice, only when the account must change it:   |
|  "Choose a new password to continue.")           |
|                                                  |
| Current password *                               |
| [______________________________]                 |
|                                                  |
| New password * (at least 12 characters)          |
| [______________________________]                 |
|                                                  |
| Repeat the new password *                        |
| [______________________________]                 |
|                                                  |
| (error text per field, after a refusal)          |
| [ Change password ]                              |
+--------------------------------------------------+
```

The side menu gets a link "Change password" above "Sign out" for every role.
